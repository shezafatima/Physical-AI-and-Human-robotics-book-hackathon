# ADR 005: Translation

## Status
Accepted

## Context
The coursebook could include optional translation features to make it accessible to a broader audience. There was a decision to be made about whether to implement multilingual support.

## Decision
We will implement optional Urdu translation feature as a bonus capability, including:

- Translation of course content to Urdu
- Language switching functionality
- Cultural adaptation of examples where appropriate

This will be optional and built on top of the core English content.

## Rationale
Translation makes the coursebook accessible to Urdu-speaking students, expanding its reach. Implementing as an optional feature allows for broader accessibility while maintaining focus on the core English content.

## Consequences
- Positive: Broader accessibility for Urdu-speaking students
- Positive: Inclusive learning environment
- Negative: Additional complexity for translation management
- Negative: Requires translation maintenance
