# Data Model: Frontend-Backend Integration for Embedded RAG Chatbot

**Feature**: 1-frontend-backend-integration
**Created**: 2025-12-18
**Status**: Complete

## User Query Entity

**Description**: Represents a user's question along with optional context from selected text

**Fields**:
- `message` (string, required): The main question or text input from the user
- `selected_text` (string, optional): Text that the user has selected on the page for context
- `context_mode` (enum, required): How to process the query (values: "full_content", "selected_text")
- `session_id` (string, optional): Identifier to maintain conversation context across multiple queries

**Validation Rules**:
- `message` must be between 10 and 1000 characters
- `selected_text` must be between 10 and 5000 characters if provided
- `context_mode` must be one of the allowed values

## Backend Response Entity

**Description**: Represents the response generated by the RAG agent with source citations

**Fields**:
- `response` (string, required): The AI-generated answer to the user's query
- `sources` (array of strings, optional): Citations to source documents used in the response
- `confidence` (string, required): Confidence level of the response (values: "high", "medium", "low", "insufficient_data")
- `error` (string, optional): Error message if processing failed
- `status` (enum, required): Processing status (values: "success", "error", "timeout")
- `context` (object, optional): Additional context information including retrieved documents
- `timestamp` (string, required): ISO 8601 formatted timestamp of response generation

**Validation Rules**:
- `response` must be between 10 and 10000 characters
- `confidence` must be one of the allowed values
- `status` must be one of the allowed values

## Chat Session Entity

**Description**: Container for maintaining conversation history within a single session

**Fields**:
- `session_id` (string, required): Unique identifier for the chat session
- `messages` (array of objects, required): Array of message objects representing the conversation history
- `timestamp` (string, required): ISO 8601 formatted timestamp when the session started
- `active` (boolean, required): Indicates if the session is currently active

**Validation Rules**:
- `session_id` must be a valid UUID format
- `messages` array must not exceed 50 items
- `timestamp` must be in valid ISO 8601 format

## Message Object

**Description**: Represents a single message in the chat session history

**Fields**:
- `id` (string, required): Unique identifier for the message
- `role` (enum, required): Role of the message sender (values: "user", "assistant")
- `content` (string, required): The text content of the message
- `timestamp` (string, required): ISO 8601 formatted timestamp of message creation
- `sources` (array of strings, optional): Source citations if this is an assistant message

**Validation Rules**:
- `role` must be one of the allowed values
- `content` must be between 1 and 10000 characters
- `timestamp` must be in valid ISO 8601 format
